# SIGA · Inteligencia académica

Suite de siete aplicaciones para la gestión académica en educación superior: horarios sin topes, mapa de calor de salas, demanda y proyección de secciones, estrés de malla, convalidaciones, fechas de exámenes y malla interactiva.

- `index.html` — landing comercial
- `demo.html` — demostración interactiva de los módulos
- `convalidaciones/` — módulo de convalidaciones y malla
- `marca/` — logotipos (SVG y PNG)
